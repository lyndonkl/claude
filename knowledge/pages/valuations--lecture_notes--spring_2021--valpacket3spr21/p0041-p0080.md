## p.41 — Valuing Gulf Oil: setup and inputs

**Teaches:** Sets up the valuation of Gulf Oil, a 1984 takeover target at $70 per share, as a natural-resource firm whose undeveloped reserves can be valued as a real option. ## p.42 — Valuing Gulf Oil's undeveloped reserves with Black-Scholes

**Teaches:** Maps the natural-resource inputs to Black-Scholes call inputs and computes the value of Gulf Oil's undeveloped reserves as a call option. The underlying asset value is discounted back for the development lag because cash flows are lost during development; the annual net production revenue rate acts as a dividend yield.

**Formulas:** Value of underlying asset S = (reserves in barrels) * (oil price per barrel - production cost per barrel) / (1 + dividend yield)^(development lag in years) = 3038 * ($22.38 - $7) / 1.05^2 = $42,380.44 million. Exercise price K = reserves * development cost per barrel = 3038 * $10 = $30,380 million. Call Value = S * e^(-y*t) * N(d1) - K * e^(-r*t) * N(d2), where y = dividend yield (net production revenue / value of developed reserves), t = time to expiration (relinquishment life), r = riskless rate, N(.) = standard normal CDF.

**Example:** Inputs: S = $42,380.44m; K = $30,380m; t = 12 years (relinquishment life); variance = 0.03 (variance in oil prices); r = 9%; dividend yield y = 5%. Black-Scholes output: d1 = 1.6548, N(d1) = 0.9510; d2 = 1.0548, N(d2) = 0.8542. Call Value = 42,380.44 * e^((-0.05)(12)) * 0.9510 - 30,380 * e^((-0.09)(12)) * 0.8542 = $13,306 million = value of undeveloped reserves.

**Compute:** DETERMINISTIC — inputs (reserves, price, cost, lag, life, variance, riskless rate, yield) → call value via Black-Scholes with dividend yield.

## p.48 — Caution: opportunities are not options (exclusivity spectrum)

**Teaches:** Not every opportunity qualifies as a valuable option. The value captured depends on three spectra: (1) whether the first investment is necessary for the second (from "not necessary" to "pre-requisite"); (2) competitive advantage on the second investment (from zero competitive advantage → option has no value, to an exclusive right → 100% of option value / option has high value); (3) whether the second investment earns excess returns (zero excess returns → no value; large sustainable excess returns → high value). Along the increasing competitive-advantage / barriers-to-entry axis the ordering runs: first-mover advantage < technological edge < brand name < telecom licenses < pharmaceutical patents.

**Rules:** Option value requires: the first investment be a prerequisite for the second; some degree of exclusivity/competitive advantage on the second investment; and the second investment must offer excess returns. With zero competitive advantage or zero excess returns, the expansion "option" has no value.

**Compute:** JUDGMENT — classification of competitive position.

**Tags:** real-options, exclusivity, competitive-advantage, barriers-to-entry, option-to-expand

## p.49 — The real options test for expansion options

**Teaches:** Applies the three-part real-options test to expansion options. (1) Options test: underlying asset = the expansion project; contingency: if PV of cash flows from expansion > expansion cost, payoff = PV - expansion cost; if PV < expansion cost, payoff = 0. (2) Exclusivity test: barriers range from strong (exclusive government licenses) to weaker (brand name, market knowledge) to weakest (first mover). (3) Pricing test: the underlying is not traded so value and volatility must be estimated; licenses are sometimes traded but diffuse expansion options are not; the exercise cost is not known precisely and may evolve over time. Conclusion: using option pricing models to value expansion options yields extremely noisy estimates and may attach inappropriate premiums to DCF estimates.

**Rules:** Payoff rule: payoff = PV of expansion CF - expansion cost if positive, else 0. Barrier strength ranking: exclusive licenses > brand name / market knowledge > first mover.

**Compute:** JUDGMENT — tests are qualitative screens.

**Tags:** real-options, options-test, exclusivity, expansion-options, estimation-noise

## p.52 — Airbus abandonment option: mapping to put inputs

**Teaches:** Maps the Airbus/Lear deal to put-option inputs. The dividend yield captures the fact that the project's present value erodes as cash flows are paid out over its life — approximated as 1/n per year where n is project life.

**Formulas:** S = PV of cash flows from project = $480 million. K = salvage value from abandonment = $400 million. Variance in underlying asset value = 0.16. **Rules:** Heuristic: for a finite-life project, set dividend yield = 1/n (n = project life in years) to capture annual value leakage from cash flows.

## p.53 — Should Airbus enter the joint venture? Put value and decision

**Teaches:** Computes the abandonment put value and shows it flips the investment decision: the raw NPV is -$20 million, but adding the abandonment option value of $73.23 million gives a total NPV of +$53.23 million, so the venture is worth taking.

**Formulas:** Value of Put = K * e^(-r*t) * (1 - N(d2)) - S * e^(-y*t) * (1 - N(d1)), where K = strike (salvage value), S = underlying value, r = riskless rate, y = dividend yield, t = option life, N(.) = standard normal CDF.

**Example:** Put = 400 * e^((-0.06)(5)) * (1 - 0.4624) - 480 * e^((-0.033)(5)) * (1 - 0.7882) = $73.23 million. Total NPV with abandonment option = -$20 million + $73.23 million = $53.23 million.

**Compute:** DETERMINISTIC — S, K, r, y, t, variance → put value; put value + NPV → decision.

## p.54 — Implications of abandonment options for investment analysis / valuation

**Teaches:** Having an option to abandon can make otherwise unacceptable projects acceptable. Other things equal, attach more value to companies with (a) more cost flexibility — more of project costs are variable rather than fixed; and (b) fewer long-term contracts/obligations with employees and customers, since these add to abandonment cost. These actions cost the firm some value, but that cost must be weighed against the increase in the value of the abandonment option.

**Rules:** Prefer variable over fixed costs and fewer long-term commitments when abandonment optionality is valuable; trade off the direct cost of flexibility against option value gained.

## p.56 — The value of flexibility (concept)

**Teaches:** Firms maintain excess debt capacity or larger cash balances than current needs warrant in order to meet unexpected future requirements. This financing flexibility has value but also a cost: excess debt capacity means the firm gives up value and carries a higher cost of capital than at its optimum. The value of flexibility can be analyzed in an option-pricing framework: the firm holds cash and debt capacity to have the option to take unanticipated future projects.

## p.57 — The value of flexibility: payoff diagram

**Teaches:** Payoff diagram for financing flexibility as a call option on reinvestment needs. Up to expected (normal) reinvestment needs that can be financed without flexibility, the flexibility is unused and the firm just bears the cost of maintaining financing flexibility (shown as a constant negative payoff). When actual reinvestment needs exceed that normal level, the firm uses its financing flexibility to take unanticipated investments (e.g., acquisitions).

**Formulas:** Payoff when exercised = (S - K) * Excess Return / WACC, where S = actual reinvestment needs, K = reinvestment needs financeable without flexibility, and Excess Return / WACC = PV of excess returns in perpetuity (converts extra investment taken into value created).

## p.60 — Valuing flexibility at Disney: result and verdict

**Teaches:** The option with Disney's inputs is worth 1.6092% (of firm value) — the value of the option to take a project. The overall value of flexibility depends on project quality: the option to take a project is worth zero if the project has zero NPV, so the raw option value is scaled by the PV of excess returns. Since the annual value of flexibility (0.85% of value) exceeds the annual cost of maintaining it (0.58%), it pays for Disney to maintain flexibility.

## p.61 — Determinants of the value of flexibility

**Teaches:** Three determinants of the value of financing flexibility. (1) Capital constraints (external and internal): the greater the capacity to raise funds internally or externally, the less the value of flexibility. Firms with significant internal operating cash flows should value flexibility less than firms with small or negative operating cash flows (1.1). Firms with easy access to financial markets have lower flexibility value than firms without such access (1.2). (2) Unpredictability of reinvestment needs: the more unpredictable a firm's reinvestment needs, the greater the value of flexibility. (3) Capacity to earn excess returns: the greater the capacity to earn excess returns, the greater the value of flexibility. Firms that cannot earn or sustain excess returns get no value from flexibility (1.3).

**Rules:** More internal cash flow / easier market access → lower flexibility value. More unpredictable reinvestment needs → higher flexibility value. No excess returns → zero flexibility value.

**Compute:** JUDGMENT.

**Tags:** financing-flexibility, capital-constraints, excess-returns, determinants

## p.62 — E. Valuing equity as an option (concept)

**Teaches:** Equity is a residual claim: equity holders receive whatever cash flows remain after all other financial claim-holders (debt, preferred stock, etc.) are satisfied, and the same applies in liquidation. Limited liability protects equity investors in publicly traded firms: if firm value is less than outstanding debt, they cannot lose more than their investment. This residual-claim-plus-limited-liability structure makes equity a call option on the firm's assets.

## p.66 — Valuing equity as a call option (base case result)

**Teaches:** Black-Scholes valuation of equity as a call on the firm, and derivation of the implied market value of debt and the interest rate on debt. The value of debt is firm value minus equity value; the promised yield is backed out from face value versus market value of the zero-coupon debt.

## p.75 — Effects on equity of a conglomerate merger: setup and combined variance

**Teaches:** Two unrelated firms merge; because their cash flows are imperfectly correlated (0.4), the combined firm's variance is lower than a value-weighted average, which (per option logic) hurts equity and helps debt.

**Formulas:** Variance in combined firm value = w1^2 * sigma1^2 + w2^2 * sigma2^2 + 2 * w1 * w2 * rho12 * sigma1 * sigma2. Symbols: w1, w2 = value weights of the two firms (0.4 and 0.6 here). sigma1, sigma2 = standard deviations of firm values. rho12 = correlation between the firms' values/cashflows. Computed: (0.4)^2 (0.16) + (0.6)^2 (0.25) + 2 (0.4)(0.6)(0.4)(0.4)(0.5) = 0.154. (Note: the slide's expansion uses the correlation 0.4 with sigma terms 0.4 and 0.5 in the cross-product.)

**Data:**

| Item | Firm A | Firm B |
|---|---|---|
| Value of the firm | $100 million | $150 million |
| Face value of debt (10-yr zeros) | $80 million | $50 million |
| Maturity of debt | 10 years | 10 years |
| Std. dev. in value | 40% | 50% |
| Correlation between cashflows | 0.4 | (joint) |

Ten-year bond rate = 10%.

**Example:** Combined variance = 0.154 (std dev about 39.2%), lower than Firm B's 0.25 and barely below Firm A's 0.16 — diversification reduces combined volatility.

## p.78 — Real-world approaches to getting inputs for troubled-firm equity valuation

**Teaches:** Practical estimation procedures for each input to the equity-as-option model when valuing equity in troubled firms.

**Formulas:** If stocks and bonds are traded: sigma_firm^2 = we^2 * sigma_e^2 + wd^2 * sigma_d^2 + 2 * we * wd * rho_ed * sigma_e * sigma_d. Symbols: sigma_e^2 = variance in the stock price. we = market-value weight of equity. sigma_d^2 = variance in the bond price. wd = market-value weight of debt. rho_ed = correlation between stock and bond prices.

**Data:**

| Input | Estimation process |
|---|---|
| Value of the firm | Cumulate market values of equity and debt; or value the assets in place using FCFF and WACC; or use cumulated market value of assets if traded. |
| Variance in firm value | If stocks and bonds are traded, use the weighted variance formula above; if not traded, use variances of similarly rated bonds; or use average firm-value variance from the industry in which the company operates. |
| Value of the debt | If debt is short term, use only the face/book value of debt; if long term and coupon-bearing, add the cumulated nominal value of the coupons to the face value of the debt. |
| Maturity of the debt | Face-value-weighted duration of bonds outstanding; or if not available, use weighted maturity. |

**Rules:** Short-term debt → face/book value; long-term coupon debt → face value + cumulated nominal coupons. Prefer face-value-weighted duration over weighted maturity for the option life.

**Compute:** MIXED — the variance formula and weighted duration are deterministic given market data; choosing proxies (industry variance, similarly rated bonds) is judgment.

## p.42 — Valuing Gulf Oil's undeveloped reserves with Black-Scholes

**Teaches:** Maps Gulf Oil's undeveloped reserves into Black-Scholes call-option inputs and computes the option value. The underlying asset value is the value of estimated reserves discounted back for the development lag; the exercise price is the development cost; time to expiration is the relinquishment life; variance is the variance in oil prices; the dividend yield is net production revenue as a fraction of developed-reserve value (the cost of delay).
**Formulas:**
- Value of underlying asset S = Reserves × (Oil price − Production cost per barrel) / (1 + dividend yield)^(development lag) = 3038 × ($22.38 − $7) / 1.05^2 = $42,380.44 million. (Reserves = 3038 million barrels; 5% = dividend yield used to discount for the 2-year development lag.)
- Exercise price K = Reserves × development cost per barrel = 3038 × $10 = $30,380 million.
- Call Value = S·e^(−y·t)·N(d1) − K·e^(−r·t)·N(d2), where y = dividend yield = 5%, r = riskless rate = 9%, t = 12 years, variance σ² = 0.03. Here: Call = 42,380.44·e^((−0.05)(12))·(0.9510) − 30,380·e^((−0.09)(12))·(0.8542) = $13,306 million. (N(·) = cumulative standard normal; d1 = 1.6548, N(d1) = 0.9510; d2 = 1.0548, N(d2) = 0.8542.)
**Example:** Gulf Oil undeveloped reserves: S = $42,380.44M, K = $30,380M, t = 12 yrs, σ² = 0.03, r = 9%, y = 5% → call value = $13,306 million.
**Compute:** DETERMINISTIC — inputs (reserves, prices, costs, lag, life, variance, riskless rate, yield) → Black-Scholes call value.
**Tags:** black-scholes, undeveloped-reserves, real-options, gulf-oil

## p.48 — Caution: opportunities are not options

**Teaches:** Not every opportunity deserves option value. The page is a diagram of three sliding scales. Together they determine how much of computed option value a firm can actually claim:
1. Is the first investment necessary for the second? Ranges from "not necessary" to "pre-requisite".
2. Competitive advantage on the second investment. Zero advantage → no option value; an exclusive right → 100% of option value.
3. Excess returns on the second investment. Zero excess returns → option has no value; large sustainable excess returns → option has high value.

A spectrum of increasing competitive advantage / barriers to entry runs: first-mover < technological edge < brand name < telecom licenses < pharmaceutical patents.
**Rules:** Attach option value only in proportion to exclusivity and sustainability of excess returns: exclusive right + sustainable excess returns → full option value; no barriers + zero excess returns → zero option value.
**Compute:** JUDGMENT — assessing exclusivity and competitive advantage.
**Tags:** real-options, competitive-advantage, barriers-to-entry, option-value-caveats

## p.49 — The real options test for expansion options

**Teaches:** Applies the three-part real options test to expansion options. Options test: underlying asset is the expansion project; contingency payoff is PV of expansion CF − expansion cost if positive, else 0. Exclusivity test: barriers range from strong (exclusive government licenses) to weaker (brand name, market knowledge) to weakest (first mover). Pricing test: the underlying is not traded so value and volatility must be estimated; licenses are sometimes traded but diffuse expansion options are not; the exercise cost is imprecise and may evolve. Conclusion: option pricing for expansion options yields extremely noisy estimates and may attach inappropriate premiums to DCF values.
**Rules:** Payoff = PV of expansion CF − expansion cost if PV > cost; 0 otherwise. Be skeptical of expansion-option premiums when exclusivity is weak or inputs are untradeable/imprecise.
**Compute:** JUDGMENT — evaluating whether an expansion opportunity qualifies as an option.
**Tags:** real-options-test, option-to-expand, exclusivity, valuation-caveats

## p.54 — Implications of abandonment options for investment analysis

**Teaches:** Having an abandonment option can make otherwise unacceptable projects acceptable. Other things equal, attach more value to companies with (a) more cost flexibility — more variable costs rather than fixed costs — and (b) fewer long-term contracts/obligations with employees and customers, since these raise the cost of abandoning. These actions cost the firm some value, which must be weighed against the increased value of the abandonment option.
**Rules:** Prefer variable-cost structures and fewer long-term commitments when abandonment risk matters; trade off the direct cost of flexibility against the option value gained.
**Compute:** JUDGMENT — qualitative trade-off.
**Tags:** option-to-abandon, cost-flexibility, investment-analysis

## p.56 — The value of flexibility

**Teaches:** Firms maintain excess debt capacity or larger-than-needed cash balances to meet unexpected future requirements. This flexibility has value but also a cost: excess debt capacity means the firm gives up value and carries a higher cost of capital. Flexibility can be analyzed in an option framework: large cash balances and excess debt capacity are held to have the option to take projects that might arise in the future.

## p.60 — Valuing flexibility at Disney

**Teaches:** With the p.59 inputs, the option value is 1.6092% of firm value — the value of the option to take a project, but the overall value of flexibility depends on project quality: the option to take a zero-NPV project is worth nothing. Disney earns 18.69% on projects with a 12.22% cost of capital, so its annual excess return is 6.47%; assuming these excess returns persist in perpetuity, annual flexibility value = 1.6092% × (0.0647 / 0.1222) = 0.85% of value. The cost of maintaining flexibility is 12.22% − 11.64% = 0.58% annually (current WACC minus optimal WACC). Since 0.85% > 0.58%, it pays Disney to maintain flexibility.
**Formulas:** Value of Flexibility (annual, % of firm value) = Option value % × (Excess Return / WACC), where Excess Return = return on capital − cost of capital. Cost of flexibility = current cost of capital − cost of capital at optimal debt ratio.
**Rules:** Maintain flexibility only if annual value of flexibility > annual cost of flexibility (here 0.85% > 0.58% → maintain).
**Example:** Disney: option value 1.6092%; excess return 6.47% (= 18.69% − 12.22%); flexibility value = 1.6092% × (0.0647/0.1222) = 0.85% of value; cost = 12.22% − 11.64% = 0.58% → flexibility worth keeping.

## p.61 — Determinants of the value of flexibility

**Teaches:** Three determinants of flexibility value. (1) Capital constraints (external and internal): the greater the capacity to raise funds internally or externally, the less flexibility is worth — firms with significant internal operating cash flows should value flexibility less than firms with small or negative operating cash flows (1.1), and firms with easy access to financial markets should value it less than firms without access (1.2). (2) Unpredictability of reinvestment needs: the more unpredictable, the greater the value of flexibility. (3) Capacity to earn excess returns: the greater it is, the greater the value of flexibility — firms unable to earn or sustain excess returns get no value from flexibility (1.3).
**Rules:** Flexibility value increases with capital constraints, reinvestment unpredictability, and excess-return capacity; zero excess returns → zero flexibility value.
**Compute:** JUDGMENT — qualitative determinants.
**Tags:** financing-flexibility, capital-constraints, excess-returns, determinants

## p.62 — E. Valuing equity as an option

**Teaches:** Equity is a residual claim: equity holders receive all cash flows left after debt, preferred stock, and other financial claimants are satisfied; in liquidation they receive whatever remains after all debts and claims are paid. Limited liability protects equity investors in publicly traded firms: if firm value falls below the outstanding debt, they cannot lose more than their investment. This residual-claim-with-limited-liability structure makes equity a call option on the firm.
**Compute:** JUDGMENT — conceptual foundation.

## p.66 — Valuing equity as a call option (solution)

**Teaches:** Solves the p.64-65 example: equity is the call value, debt is firm value minus equity, and the implied interest rate on debt comes from the ratio of face value to market value of debt over the maturity. **Example:** Firm $100M, debt face $80M, 10-yr, σ² = 0.16, r = 10% → equity $75.94M, debt $24.06M, implied debt rate 12.77%.

## p.75 — Effects on equity of a conglomerate merger (setup)

**Teaches:** Two unrelated firms plan to merge; because their cash flows are imperfectly correlated (ρ = 0.4), the combined firm's variance is lower than a value-weighted average of the individual variances — diversification reduces firm risk, which matters for the option values of equity and debt.
**Formulas:** Variance in combined firm value = w1²·σ1² + w2²·σ2² + 2·w1·w2·ρ12·σ1·σ2. Here w1, w2 = value weights of the two firms (0.4 and 0.6). σ1², σ2² = variances of the two firms' values. ρ12 = correlation between cash flows. Plugging in: (0.4)²(0.16) + (0.6)²(0.25) + 2(0.4)(0.6)(0.4)(0.4)(0.5) = 0.154.
**Data:**

| Item | Firm A | Firm B |
|---|---|---|
| Value of the firm | $100 million | $150 million |
| Face value of debt (10-yr zeros) | $80 million | $50 million |
| Maturity of debt | 10 years | 10 years |
| Std. dev. in value | 40% | 50% |
| Correlation between cashflows | 0.4 (between A and B) | — |

Ten-year bond rate = 10%.
**Compute:** DETERMINISTIC — weights, variances, correlation → combined variance (0.154).

## p.78 — Getting inputs for valuing equity in troubled firms

**Teaches:** Practical estimation methods for each input to the equity-as-option model in real (troubled) firms.
**Formulas:** If stocks and bonds are traded: σ²_firm = we²·σe² + wd²·σd² + 2·we·wd·ρed·σe·σd, where σe² = variance in the stock price, we = market-value weight of equity, σd² = variance in the bond price, wd = market-value weight of debt, ρed = correlation between stock and bond prices.
**Data:**

| Input | Estimation process |
|---|---|
| Value of the firm | Cumulate market values of equity and debt; or value the assets in place using FCFF and WACC; or use cumulated market value of assets, if traded. |
| Variance in firm value | If stocks and bonds are traded, use the weighted-variance formula above; if not traded, use variances of similarly rated bonds; or use average firm value variance from the company's industry. |
| Value of the debt | If the debt is short term, use only the face/book value of the debt; if long term and coupon-bearing, add the cumulated nominal value of the coupons to the face value of the debt. |
| Maturity of the debt | Face-value-weighted duration of bonds outstanding; if not available, use weighted maturity. |

**Rules:** Short-term debt → use face/book value; long-term coupon debt → face value + cumulated nominal coupons; maturity → face-value-weighted duration, else weighted maturity.
**Compute:** MIXED — the variance formula and weighted duration are deterministic from market data; choosing among the alternative estimation routes is judgment.

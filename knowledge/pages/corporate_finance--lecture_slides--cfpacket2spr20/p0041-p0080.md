## p.43 — Mechanics of Cost of Capital Estimation

**Teaches:** The four-step procedure for finding the optimal debt ratio via the cost-of-capital approach: (1) Estimate cost of equity at each debt level — more debt makes equity riskier, so levered beta and cost of equity rise (uses the levered-beta calculation). (2) Estimate cost of debt at each debt level — more debt increases default risk, lowers bond ratings, and raises the cost of debt (ratings are estimated from the interest coverage ratio = EBIT/Interest expense). (3) Compute the cost of capital at each debt level. (4) Compute the effect on firm value and stock price.
**Rules:** Use interest coverage ratio (EBIT/Interest expense) to infer a synthetic bond rating at each hypothetical debt level.
**Compute:** DETERMINISTIC once the ratings table and inputs are fixed (debt ratio → levered beta → cost of equity; debt ratio → coverage → rating → cost of debt → WACC).

## p.47 — Estimating Cost of Debt at Each Debt Ratio

**Teaches:** The mechanics of the cost-of-debt column, shown for 0% and 10% debt. Fix total firm value at the current market value ($121,878 equity + $15,961 debt = $137,839m). Dollar debt at each ratio = ratio × firm value. Operating numbers (EBITDA $12,517, Depreciation $2,485, EBIT $10,032) are held constant across debt ratios. Interest = pre-tax cost of debt × dollar debt. Interest coverage = EBIT/Interest → synthetic rating from the ratings table → pre-tax cost of debt = riskless rate + spread. At 10% debt: debt = $13,784, interest = $434, coverage = 23.10 → AAA → pre-tax cost of debt 3.15%.
**Formulas:** $ Debt = Debt ratio × Firm value ($137,839m). Interest expense = Pre-tax cost of debt × $ Debt. Interest coverage ratio = EBIT / Interest expense. Pre-tax cost of debt = Riskless rate + default spread (from rating). D/E = D/(D+E) ÷ (1 − D/(D+E)), e.g. 10/90 = 0.1111.
**Rules:** Rating is read off the coverage-to-rating table (p.48); the calculation is circular (cost of debt determines interest, interest determines coverage, coverage determines rating/cost of debt) so it may need iteration.
**Example:** Disney at 0% debt: debt $0, interest $0, coverage ∞ → AAA → 3.15%. At 10%: debt $13,784m, interest $434m, coverage 23.10 → AAA → 3.15%.
**Compute:** DETERMINISTIC given the ratings table (debt ratio + firm value + EBIT + T.bond rate → rating, pre-tax cost of debt), with iteration to convergence.

## p.51 — Stated versus Effective Tax Rates

**Teaches:** Interest saves taxes only against taxable income. Disney's EBIT is $10,032m; as long as interest expense stays below that, interest is fully deductible at the 36.1% marginal rate (true through 60% debt, where interest = $9,511m). At 70% debt, interest ($11,096m) exceeds EBIT, so the tax benefit is capped at EBIT × marginal rate, and the effective tax rate used on debt drops.
**Formulas:** Maximum Tax Benefit = EBIT × Marginal Tax Rate = $10,032m × 0.361 = $3,622m. Adjusted Marginal Tax Rate = Maximum Tax Benefit / Interest Expenses = $3,622 / $11,096 = 32.64%.
**Rules:** If interest expense > EBIT, replace the marginal tax rate with (EBIT × marginal rate) / interest expense when computing after-tax cost of debt.
**Example:** Disney at 70% debt: interest $11,096m > EBIT $10,032m → adjusted tax rate 32.64% instead of 36.1%.
**Compute:** DETERMINISTIC (EBIT, marginal rate, interest expense → adjusted tax rate).

## p.56 — Effect on Firm Value: Full Valuation

**Teaches:** Values the recapitalization by full DCF. Step 1: compute FCFF. Step 2: back out the growth rate the market is impounding at the current cost of capital using a growing perpetuity. Step 3: revalue the firm at the new (lower) cost of capital with the same growth rate. The move from 7.81% to 7.16% WACC raises firm value by $39,027m.
**Formulas:**
- FCFF = EBIT(1 − tax rate) + D&A − Capex − ΔNoncash WC = 10,032(1 − 0.361) + 2,485 − 5,239 − 0 = $3,657m
- Firm value = FCFF0(1+g) / (Cost of Capital − g)
- Implied growth: g = (Firm Value × Cost of Capital − CF to Firm) / (Firm Value + CF to Firm) = (133,908 × 0.0781 − 3,657)/(133,908 + 3,657) = 0.0494 (4.94%)
- New firm value = 3,657(1.0494)/(0.0716 − 0.0494) = $172,935m
**Example:** Disney: current enterprise value = 121,878 + 15,961 − 3,931 (cash) = $133,908m; implied g = 4.94%; revalued at WACC 7.16% → $172,935m; increase in firm value = 172,935 − 133,908 = $39,027m.
**Compute:** DETERMINISTIC (FCFF inputs, current EV, old and new WACC → implied g and value gain).
**Tags:** firm-valuation, fcff, recapitalization, implied-growth, disney

## p.57 — Effect on Value: Incremental Approach

**Teaches:** A simpler alternative: start from the current enterprise value and capitalize only the annual financing-cost savings from moving to the optimal debt ratio. Savings grow at the riskfree rate (used as g).
**Formulas:**
- Annual financing cost at a WACC = Enterprise value × WACC
- Annual savings = EV × (old WACC − new WACC) = 133,908 × 0.0781 − 133,908 × 0.0716 = 10,458 − 9,592 = $866m
- Increase in Value = Annual Savings next year / (Cost of Capital − g) = 866 / (0.0716 − 0.0275) = $19,623m (g = riskfree rate 2.75%)
- EV after recapitalization = Existing EV + PV of savings = 133,908 + 19,623 = $153,531m
**Example:** Disney: savings $866m/yr, capitalized at (7.16% − 2.75%) → value gain $19,623m; post-recap EV $153,531m.
**Compute:** DETERMINISTIC (EV, old WACC, new WACC, g → value increase).
**Tags:** incremental-valuation, recapitalization, wacc, disney

## p.58 — From Firm Value to Value per Share: The Rational Investor Solution

**Teaches:** If the value gain accrues entirely to stockholders and is spread evenly across sellers and holders, divide the gain by total shares outstanding to get the per-share increase. This is the "rational" solution because it leaves investors indifferent between selling back shares and holding.
**Formulas:** Increase in value per share = Increase in firm value / shares outstanding = $19,623m / 1,800m = $10.90. New stock price = old price + increase = $67.71 + $10.90 = $78.61.
**Example:** Disney: 1,800m shares, gain $19,623m → +$10.90/share; price $67.71 → $78.61.
**Compute:** DETERMINISTIC (value gain, share count, current price → new price).
**Tags:** value-per-share, buyback, recapitalization, disney

## p.59 — The More General Solution, Given a Buyback Price

**Teaches:** When the buyback happens at a specified price (not necessarily the rational price), the per-share value depends on that price. Procedure: compute shares remaining after the buyback, compute post-recap equity value, divide.
**Formulas:**
- Increase in Debt = Debt at optimal − Current Debt
- # Shares after buyback = # Shares before − (Increase in Debt / Share Price used for buyback)
- Equity value after buyback = Optimal Enterprise value + Cash − Debt at optimal
- Value per share after buyback = Equity value after buyback / Number of shares after buyback
**Rules:** Buying back below the rational price transfers value to remaining holders; buying at the rational price leaves everyone indifferent.
**Compute:** DETERMINISTIC (buyback price, debt increase, optimal EV, cash, debt → post-buyback value per share).
**Tags:** buyback-price, value-per-share, recapitalization

## p.61 — Back to the Rational Price ($78.61): The Proof

**Teaches:** Repeats the buyback computation at $78.61 and shows it is a fixed point. Buying back at $78.61 leaves post-buyback value per share exactly $78.61. That proves it is the self-consistent ("rational") price at which sellers and holders are treated equally.
**Example:** Shares after buyback = 1,800 − 39,175/78.61 = 1,301.65m. Equity after buyback = 153,531 + 3,931 − 55,136 = $102,326m. Value per share = 102,326 / 1,301.65 = $78.61 (equals the buyback price).

## p.62 — What If Something Goes Wrong? The Downside Risk

**Teaches:** Two ways to handle uncertainty in the optimal debt ratio. (A) Sensitivity/"what if" analysis: the optimum depends on operating income, tax rates and macro variables; focus on the key driver (operating income), use its historical volatility, and ask what-if questions. (B) Economic scenario approach: compute the optimal debt ratio under distinct macro scenarios (e.g. boom, regular economy, recession for a cyclical firm). Alternatively, impose constraints — require a minimum bond rating at the optimal, or cap the book debt ratio — to limit downside exposure.
**Rules:** Either stress-test the inputs or impose a rating/book-debt-ratio constraint; both are protections against downside risk in operating income.
**Compute:** MIXED — recomputing the optimum under each scenario is deterministic; choosing scenarios and constraints is judgment.
**Tags:** sensitivity-analysis, downside-risk, rating-constraint, capital-structure

## p.65 — Constraints on Ratings

**Teaches:** Management often specifies a desired minimum rating. The rating constraint is driven by three factors. It protects against downside risk in operating income (so don't also do a separate downside analysis — do not do both). A ratings drop might itself hurt operating income. And there is an ego factor in high ratings. Caveat: every rating constraint has a cost — the difference between the unconstrained firm value and the value with the constraint — and managers should be made aware of that cost.
**Rules:** Cost of a rating constraint = Unconstrained firm value − Firm value with constraint. Do not double-protect (rating constraint AND downside-scenario haircut).

## p.67 — What If You Do Not Buy Back Stock

## p.72 — The US Tax Reform Act of 2017: Effects on the Optimal Debt Ratio

**Teaches:** Two channels through which the 2017 tax reform lowers optimal debt ratios. (1) The marginal federal tax rate on US income fell from 35% to 21% — holding all else constant, that lowers the optimal debt ratio for all firms. (2) Interest deductibility is limited to 30% of EBITDA (until 2022) and 30% of EBIT (after 2022); in the cost of capital calculation this shows up as a lower tax rate on debt when interest exceeds the cap.
**Formulas:** Tax rate if Interest Expense > 30% of EBITDA = Marginal Tax Rate × (0.30 × EBITDA) / Interest Expense.
**Rules:** If interest expense > 30% of EBITDA (or EBIT after 2022), scale down the tax rate used for the after-tax cost of debt by (0.30 × EBITDA)/Interest.

## p.75 — Limitations of the Cost of Capital Approach

**Teaches:** Three limitations: (1) It is static — the most critical number is operating income, and if it changes the optimal debt ratio changes. (2) It ignores indirect bankruptcy costs — operating income is assumed to stay fixed as the debt ratio and rating change, though in reality distress erodes it. (3) Beta and ratings — it rests on rigid assumptions about how market risk and default risk get borne as the firm borrows more and what those risks cost.
**Compute:** JUDGMENT (conceptual critique).
**Tags:** cost-of-capital-approach, limitations, indirect-bankruptcy-costs

## p.76 — II. Enhanced Cost of Capital Approach

**Teaches:** Two fixes to the standard approach. (1) Distress-cost-affected operating income: build indirect bankruptcy costs into expected operating income — as the firm's rating declines, adjust operating income down to reflect the losses that occur when customers, suppliers and investors react. (2) Dynamic analysis: instead of a single operating income number, draw from a distribution of operating income, allowing for different outcomes.
**Compute:** MIXED — mechanics are deterministic once the distress haircuts/distribution are specified; specifying them is judgment.

## p.79 — Extending the Approach to Financial Service Firms

**Teaches:** Three problems with applying the standard approach to banks and financial service firms. (1) Interest coverage spreads must be estimated separately for financial firms — using manufacturing-company spreads gives absurdly low ratings for even the safest banks and very low optimal debt ratios. (2) Debt is hard to define on a financial firm's balance sheet (deposits, repos, short-term financing); one solution is to focus only on tightly defined long-term debt and coverage ratios using only long-term interest expenses. (3) Financial firms are regulated with capital ratios defined in book-value terms; moving to an optimal market-value debt ratio could violate book capital ratios and endanger the firm.
**Rules:** For financial firms: use financial-sector-specific coverage-to-spread mappings; define debt narrowly as long-term debt; respect book-value regulatory capital constraints.
**Compute:** JUDGMENT.
**Tags:** financial-service-firms, banks, capital-structure, regulatory-capital

## p.80 — Capital Structure for a Bank: A Regulatory Capital Approach

**Teaches:** For banks, capital structure is driven by regulatory capital requirements rather than a WACC optimization. Worked example: a bank with $100m of loans, $6m book equity, a 5% regulatory equity-capital requirement; it wants to grow loans by $50m to $150m and raise its equity ratio to 7% of loans. The need for external equity at a bank depends on four factors.

- Growth rate: higher growth → more external equity.
- Existing vs target capitalization: undercapitalized → more external equity.
- Current earnings: less earnings → more external equity.
- Current dividends: more dividends → more external equity.
**Formulas:** New equity needed = Target equity ratio × Loans after expansion − Existing equity = 7% × $150m − $6m = $10.5m − $6m = $4.5m.
**Example:** Bank: loans $100m → $150m; equity ratio target 7%; equity after expansion $10.5m; existing equity $6.0m; new equity needed $4.5m.
**Compute:** DETERMINISTIC (loan base, target ratio, existing equity → new equity needed); factors (a)–(d) frame the judgment.
**Tags:** banks, regulatory-capital, external-equity, capital-structure
